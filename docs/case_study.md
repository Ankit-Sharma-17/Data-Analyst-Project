# Case Study: Reducing Telecom Churn Through Segment Intelligence

## Business Context

A telecom provider wants to reduce preventable churn while preserving revenue growth.

## Objective

Build an analytics framework that isolates retention risk by segment and prioritizes the highest business-impact interventions.

## Approach

1. Generate customer-level monthly profile data
2. Clean and segment records in ETL
3. Compute KPI and segment-level outcomes
4. Build SQL views for dashboard consumers
5. Translate findings into targeted retention actions

## Key Outputs

- KPI snapshot for leadership
- High-risk segment ranking
- Churn driver comparison table
- Visual pack for stakeholder communication

## Example Decisions Enabled

- Prioritize customers in `Critical` risk band with high monthly revenue
- Rework onboarding/support for channels with high churn
- Deploy payment-reminder automations where delay patterns are strongest

## Resume-Ready Impact Statement

"Designed and delivered an end-to-end telecom customer analytics pipeline (Python + SQL), producing churn segmentation and ARPU diagnostics that support targeted retention strategy and dashboard reporting."
